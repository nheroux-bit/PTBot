# Output Template

## Executive Summary

Summarize qualifying deals, near-misses, and valuation implications.

## Summary Transaction Table

Include target, acquirer, announcement/close date, deal value, EV/Revenue, EV/EBITDA, EV/ARR, P/E, deal structure, and sources.

## Detailed Deal Profiles

For each qualifying deal, include target profile, acquirer profile, deal terms, multiples, strategic rationale, and analyst commentary.

## Comparable Multiples Context

Include sector-wide M&A multiple benchmarks and premium/discount analysis.

## Key Takeaways for Valuation

Translate findings into valuation guidance, caveats, and suggested next diligence steps.
